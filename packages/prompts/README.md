# HINTO Prompts

This package contains AI coach prompt and safety logic for the restart architecture.

It is intentionally independent of:

- OpenAI transport code
- Supabase table names
- app-specific view state
- legacy Amplify or Expo assumptions

Current scope:

- relationship coach system prompt
- mobile-friendly response style guidance
- contextual prompt assembly
- deterministic safety trigger detection for crisis and violence scenarios
- conversation starter helpers
